# My Portfolio

This repository hosts my professional GitHub portfolio for IS 3060.

## Description

A responsive, modern portfolio website showcasing my skills, projects, and professional experience as an Information Systems student at the University of Utah.

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Custom styling with responsive design
- **Bootstrap 5** - Responsive framework
- **Font Awesome** - Icons
- **JavaScript** - Navigation interactivity

## Features

- Responsive mobile-first design
- Sticky navigation menu
- Smooth hover effects and transitions
- Professional color scheme
- Project showcase with cards
- Skills display
- Contact information
- Resume section (coming soon)

## Website

https://evelyn-perkins.github.io/

## Sections

- **About Me** - Professional background and interests
- **Skills** - Technical skills and tools
- **Projects** - Portfolio projects (updated throughout the semester)
- **Resume** - Downloadable resume (coming soon)
- **Contact** - Email and social links

## How to Use

1. Clone the repository
2. Update the contact information in `index.html` with your email and social links
3. Add project details as you complete them
4. Replace "Resume coming soon" with a link to your PDF resume when ready
5. Push changes to GitHub Pages

The site automatically deploys to your GitHub Pages URL.
